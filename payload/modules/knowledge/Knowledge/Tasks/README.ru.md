# Tasks — задачи

Спецификация текущей задачи: цель, детали, решения по ходу, прогресс и итоги для Знаний. По ней
работу продолжают в новой сессии, другим Агентом или другим человеком. Тип `task`, срок жизни —
до сбора итогов.

## Когда создавать

- Задача займёт больше одной сессии или требует исследования и спецификации.
- По ходу будут приниматься решения, которые надо помнить до конца задачи.

## Когда не создавать

- Мелочь, которая закончится в этой сессии. Идея на будущее — в Plans.

## Статусы

- `active` — в работе; `blocked` — ждёт внешнего (причину запиши в «Прогресс»).
- `done` — сделано; итоги разносятся по Decisions, Gotchas, Entities, Examples (`wrap-up`, `kb-review`),
  затем файл задачи удаляется с согласия человека — он остаётся в истории git.
- Обновляя прогресс, ставь `verified` на сегодня: задачи `active`/`blocked` без обновлений 14 дней
  попадают в `Toolbox/tb kb stale`.

Затронутые ресурсы — в поле `resources`, ветки — в «Спецификации».

## Имя и создание

Имя — суть задачи: `auth-token-refresh.md`. Нужны артефакты — задача-папка `Tasks/<slug>/index.md` (`--folder`).

`Toolbox/tb kb new task auth-token-refresh --title "Обновление токенов авторизации"`

## Пример (фрагмент)

```markdown
title: "Обновление токенов авторизации"
description: "Refresh-токены в api и web: ротация и отзыв"
resources: [api, web]
## Прогресс
- 2026-10-08: ротация в api готова (ветка feat/refresh); дальше — web.
```
