# Коммит Знаний

Знания коммитятся сразу после правки, без просьбы человека: при параллельных сессиях иначе не понять,
какая сессия что записала. `Toolbox/tb kb commit` коммитит только указанные пути (`git commit --only`):
чужое в индексе в коммит не попадёт. Трейлер `Agent-Session: <агент>:<id> (<заголовок>)` ставится сам. Вне
`Knowledge/` команда не коммитит: остальное — по просьбе человека, отдельно, со своим scope.

## Когда

- Закончил логическую правку: заметка создана, обновлена или удалена, итоги разнесены. Один коммит —
  одна мысль; черновик посреди правки не коммить.
- Человек отменил или поправил недавно записанное (план, грабли, решение, напоминание) — это поправка
  своего коммита: `--amend`, а не новый коммит.
- Хук сообщил о незакоммиченных Знаниях сессии — закоммить или объясни человеку, почему нет.
- Человек просит не коммитить — не коммить и скажи, что правки остались в рабочем дереве.

## Порядок

0. **Заголовок сессии** — один раз за сессию, до первого коммита: `Toolbox/tb kb session title "<что делает
   сессия>"` — заголовок задачи или суть работы, коротко. По нему человек потом найдёт сессию в истории
   (`git log --grep`). Тема сменилась — задай новый. Без заголовка в трейлере только id.
1. **Пути.** Только файлы, которые правила эта сессия (`git status --short -- Knowledge/` покажет и
   чужие — их не бери). Удалённые файлы указываются так же.
2. **Проверка.** `Toolbox/tb kb lint` (Windows PowerShell: `Toolbox\tb.cmd kb lint`): ошибки в своих
   заметках исправь; спорное — спроси человека. Ссылка на незакоммиченную чужую заметку — сделай её
   отложенной (`[текст](путь.md "pending")`).
3. **Коммит:**
   ```
   Toolbox/tb kb commit Knowledge/Gotchas/uv-proxy-ssl.md Knowledge/Tasks/auth-token-refresh.md \
     -m "Грабли uv за прокси" -m "- Gotcha: uv за прокси требует SSL_CERT_FILE" \
     -m "- Задача auth-token-refresh: прогресс"
   ```
   Первое `-m` — суть (префикс `knowledge:` добавится), следующие — тезисы о смысле, а не о файлах.
4. **Поправка** своего недавнего коммита: `Toolbox/tb kb commit <пути> --amend [-m …]`.
   - Последний коммит — этой сессии и не запушен → amend (без `-m` сообщение сохраняется).
   - Поверх уже есть чужие коммиты → коммит `fixup! <тема>`. Склеивает `Toolbox/tb kb squash`, только
     при чистом рабочем дереве, когда параллельные сессии всё закоммитили. Предложи человеку, сам не
     запускай посреди чужой работы.
   - Запушенное не переписывается: будет обычный коммит.
5. **Хук pre-commit** проверяет заметки и секреты. Упал — исправь причину. Не обходи: ни `--no-verify`,
   ни `git commit-tree`, ни отключение хука. `tb kb commit` откажет, если хуки не включены (`Toolbox/tb setup`).
6. **Сообщи человеку** одной строкой: хэш, суть, файлы — `Знания: a1b2c3d «Грабли uv за прокси» (2 файла)`.
   Поправка — так же, с пометкой amend или fixup.
