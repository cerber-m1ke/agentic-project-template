# Поиск в Знаниях

Только чтение: не правь файлы, не создавай заметки, не коммить. Правки по итогам вносит основной
Агент — сразу или в `wrap-up`.

## Кто выполняет

Если твой агент умеет запускать субагентов и доступен субагент `librarian` — поручи вопрос ему:
передай вопрос и контекст (задача, ресурс, текст ошибки). Он ответит в формате ниже; если нюанс
важен, открой файлы из «Источников» сам. Иначе выполни процедуру в основной сессии.

## Процедура

1. **Поиск.** `Toolbox/tb kb search <ключевые слова>` (Windows PowerShell: `Toolbox\tb.cmd kb search …`).
   - Ищи ключевыми словами, а не вопросом целиком. Сделай 2–3 формулировки: синонимы, русские
     и английские термины, имя ресурса или библиотеки, фрагмент текста ошибки.
   - Фильтры по ситуации: `--type gotcha` для ошибки, `--type decision` перед решением,
     `--resource <name>` для ресурса, `--brief` — только заголовки.
2. **Чтение.** Открой 1–3 лучших совпадения целиком: `Toolbox/tb kb show <путь>`; связанные —
   `Toolbox/tb kb related <путь>`. Учитывай `status` и `verified`.
3. **Сверка с Ресурсами** — ключевые утверждения, а не всё подряд:
   - версии: lock-файлы и манифесты в `Resources/<name>/` (`package-lock.json`, `uv.lock`, `go.mod`,
     `Cargo.lock` и т.п.) против `applies_to`;
   - упомянутые файлы, функции, команды, ключи конфигов существуют (поиск по `Resources/<name>/`);
   - состояние ресурсов: `Toolbox/tb resources status`.
   Только чтение: не запускай сборку, установку, `git checkout`/`pull`.
4. **Ответ** строго в формате ниже.

## Формат ответа

```
Ответ: <суть по вопросу: факты, команды, имена — кратко>
Источники: Knowledge/Gotchas/<slug>.md, Knowledge/Entities/<slug>.md
Проверка: confirmed | stale? | unverifiable (почему)
Предложения по Знаниям: <что обновить, пометить, завести> | нет
```

- `confirmed` — ключевые утверждения подтверждены по Ресурсам.
- `stale?` — расхождение или признаки устаревания: версия не совпадает с `applies_to`, файл или
  функция не найдены, статус `deprecated` или упразднённый (`resolved`, `outdated`, `superseded`,
  `dropped`). Укажи, что именно.
- `unverifiable (почему)` — проверить нельзя: ресурс не склонирован, утверждение не о Ресурсах.
- Источники с разным результатом — отметь по каждому: `confirmed (uv-proxy-ssl), stale? (api: нет функции X)`.
- Пути в «Источниках» обязательны: по ним основной Агент откроет оригинал.

Если ничего не нашлось, скажи это явно — не додумывай:

```
Ответ: ничего не найдено (запросы: «…», «…», «…»)
Источники: —
Проверка: —
Предложения по Знаниям: <завести заметку, когда ответ найдётся> | нет
```
