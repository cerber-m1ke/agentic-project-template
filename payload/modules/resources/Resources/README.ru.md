# Ресурсы

Ресурсы — то, над чем работаем в проекте: git-репозитории (код, документация, скрипты) или обычные
папки (документы, данные). Содержимое и порядок внутри ресурсов шаблон не регламентирует.

## Каталог и личный набор

- `resources.toml` — каталог всех известных ресурсов проекта. Хранится в корневом git; поля описаны
  в комментариях в начале файла.
- `Resources/<name>/` — локальные ресурсы. В корневой git они не попадают (`.gitignore`).
- У каждого человека может быть склонирован любой поднабор каталога — это нормально.

## Виды ресурсов

- `kind = "git"` — отдельный репозиторий со своей историей. Клонируется командой `Toolbox/tb resources clone`;
  коммиты — внутри него: `git -C Resources/<name> …`.
- `kind = "folder"` — обычная папка без git: документы, выгрузки, крупные и бинарные данные. Её
  содержимое не версионируется корневым git; откуда его брать — в `url` или в карточке ресурса.

## Команды

| Команда | Назначение |
|---|---|
| `Toolbox/tb resources status` | Что есть локально, текущая ветка, есть ли изменения |
| `Toolbox/tb resources clone <name>…` | Склонировать ресурсы из каталога; `--all` — все |
| `Toolbox/tb resources add <url> [--name N] [--branch B] [--kind git\|folder] [--description "…"] [--clone]` | Добавить ресурс в каталог (с `--clone` — сразу склонировать) |
| `Toolbox/tb setup --clone-missing` | Склонировать все недостающие ресурсы |

На Windows (PowerShell) — `Toolbox\tb.cmd resources …`.

## Правила для Агента

- Задаче нужен ресурс, которого нет локально, — предложи человеку `Toolbox/tb resources clone <name>`.
- Если в ресурсе есть свои `AGENTS.md` или `CLAUDE.md` (в корне или в рабочем подкаталоге), прочитай их
  перед работой: внутри ресурса действуют его правила, а разные агенты подхватывают вложенные инструкции
  по-разному. Эти файлы принадлежат ресурсу — не меняй их без просьбы.
- Коммиты в ресурс-репозиторий — только внутри него и только по просьбе человека. Содержимое ресурсов
  в корневой репозиторий не попадает.
- Задача перечисляет затронутые ресурсы в поле `resources` (имена из каталога).
- Знания о ресурсе — в карточке `Knowledge/Entities/<name>.md`; путь к ней — поле `entity` в каталоге.
  Пересказ содержимого ресурса в Знания не пишем.

## Поиск

`Resources/*` исключён из корневого git, а поиск агентов (ripgrep) уважает `.gitignore`. Файл `.ignore`
в корне проекта возвращает ресурсы в поиск.
