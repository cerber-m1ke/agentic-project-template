# Финальный аудит

Только чтение; по субагенту `adopt-auditor` на блок (`prompts/final-check.md`), разделы —
`Runtime/adopt/final-audit/<блок>.md`, сюда — сводка и разделы целиком. Оркестратор перепроверяет блокеры.

## Сводка

| Блок | Итог | pass / warn / fail | Главное |
|---|---|---|---|
| A. Знания | | | |
| B. Код | | | |
| C. Секреты | | | |
| D. Данные агентов | | | |
| E. Окружение | | | |
| F. Новое окружение | | | |

Вердикт: <GO | NO-GO>. При NO-GO — блокер → сессия-исправление → повторная проверка.

## Блоки

- **A. Знания** — полнота манифестов обратным обходом источников; переаудит 10% строк
  `obsolete`/`derivable`/`duplicate`/`junk` (не меньше 15); `tb adopt gate`, `tb kb lint`.
- **B. Код** — `tb adopt inventory --compare <снимок S1>`; работа вне новых клонов; решения
  `resources.md` выполнены.
- **C. Секреты** — каждый указатель реестра разобран; файлы-секреты скопированы со сверкой сумм;
  `tb secrets scan` проекта чист.
- **D. Данные агентов** — память, транскрипты, настройки старых копий: перенесено или в архиве.
- **E. Окружение** — `tb adopt refs`: ссылки на старые пути в git, агентах, shell, Obsidian, IDE, cron, Docker.
- **F. Новое окружение** — `tb setup`, `tb agents doctor`, `tb resources status`, Знания открываются.
