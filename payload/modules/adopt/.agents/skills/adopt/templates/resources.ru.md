# Ресурсы и решения по ним

Черновик таблицы — `Runtime/adopt/inventory/<дата>/resources.md` (`tb adopt inventory`); подробности по
репозиторию — `details/` там же. Решение по каждой строке принимает человек одним пакетом.

Решения: `clone` (+ ветка), `mv` (состояние привязано к пути: снимок, «да», откат), `folder`, `secret`,
`toolbox`, `knowledge` (уходит в перенос), `push-first` (человек пушит, затем `clone`), `archive`
(git bundle или tar), `discard` (с причиной).
