# План переноса

Стартовый промпт любой сессии: «Выполни сессию <ID> по `Knowledge/Tasks/{{slug}}/plan.md`; прочитай общие
правила и свой раздел». Сессия правит только свою строку статуса, перечитав файл перед правкой. Процедура
и критерии этапов — skill `adopt`.

## Статус

| ID | Этап | Зависит от | Статус | Дата | Итог |
|---|---|---|---|---|---|
| S0 | Подготовка: start, архив невосстановимого | — | todo | | |
| S1 | Инвентаризация, решения по ресурсам | S0 | todo | | |
| S2 | Ресурсы, секреты, настройки агентов | S1 | todo | | |
| S3 | Правила и пилот | S1 | todo | | |
| S4a | Перенос: <группа источников> | S2, S3 | todo | | |
| S5 | Вопросы | S4* | todo | | |
| S6 | Консолидация | S4*, S5 | todo | | |
| S7 | Финальный аудит | S6 | todo | | |
| S8 | Очистка | S7 = GO | todo | | |

Статусы: `todo`, `doing`, `done`, `blocked: <чем>`. Сессии S4 делятся по группам источников и идут параллельно.

## Общие правила

- Старые места только читаются до S8; необратимое и внешнее — после «да» человека.
- Массово читают субагенты; ответ субагента ≤ 10 строк; пачка ≤ 12 файлов или ~60 КБ; ≤ 5 субагентов.
- Коммиты — явными путями: свои заметки и пачки — после зелёного `check`, общее — после зелёного `gate`.
- Конец сессии: строка статуса, «Прогресс» в `index.md`, предложение коммита, ответ ≤ 10 строк.

## Решения и факты проекта

<!-- Старые копии и что в них главнее, ловушки окружения, решения человека с датами. -->

## S0. Подготовка

Готово, если: задача создана, архивы невосстановимого сверены.

## S1. Инвентаризация

Готово, если: в `resources.md` решение у каждой строки, вся локальная работа учтена.

## S2. Ресурсы

Готово, если: `tb resources status` и `tb agents doctor` без замечаний.

## S3. Правила и пилот

Готово, если: `adopt.toml` с источниками, манифесты и slugmap собраны, правила проекта утверждены
человеком по пилоту.

## S4a. Перенос: <группа источников>

Источники: <имена из adopt.toml>. Готово, если: `tb adopt check <источник>` зелёный по каждому.

## S5. Вопросы

Готово, если: открытых вопросов нет или человек отложил их явно.

## S6. Консолидация

Готово, если: `tb adopt gate` зелёный, `tb kb lint` 0/0, `tb secrets scan` чисто, «Что в работе» заполнено.

## S7. Финальный аудит

Готово, если: `final-audit.md` с GO и `deletion-manifest.md` составлен.

## S8. Очистка

Готово, если: старое убрано по манифесту, задача закрыта через `wrap-up`, модуль `adopt` снят.
