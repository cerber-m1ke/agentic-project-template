# Devcontainer

Песочница для агентов. Здесь можно запускать Claude Code и Codex CLI в автономном режиме, а также
агентов и модели, которым вы доверяете меньше: они видят только контейнер и проект, а не вашу машину.
Основной способ работы — на хосте, контейнер нужен для этих случаев.

## Состав

- Debian, git, curl, ripgrep, uv (той же версии, что закреплена в `Toolbox/tb`).
- Claude Code и Codex CLI, установленные официальными установщиками. Версии — `build.args`
  в `devcontainer.json` (`CLAUDE_CODE_VERSION`, `CODEX_VERSION`): по умолчанию каналы `stable`/`latest`,
  для воспроизводимой песочницы закрепите точные версии. `devcontainer.json` принадлежит проекту.
- Пользователь `dev` без sudo.
- После создания контейнера выполняется `Toolbox/tb setup --agents claude,codex`.

## Использование

1. Откройте проект в VS Code и выберите «Dev Containers: Reopen in Container»
   (или `devcontainer up --workspace-folder .` из Dev Containers CLI).
2. В терминале контейнера запустите `claude` или `codex` и войдите один раз.
3. Автономный режим включайте только здесь, например `claude --dangerously-skip-permissions`
   или `codex --yolo`.

Обновить агентов — пересобрать контейнер («Dev Containers: Rebuild Container»).

## Оговорки

- **Windows.** Не открывайте в контейнере папку с диска хоста, а клонируйте репозиторий в том
  контейнера («Dev Containers: Clone Repository in Container Volume»). Ссылки адаптеров, которые
  контейнер создаёт в смонтированной папке, не работают для нативных агентов Windows, поэтому у
  контейнера должна быть своя копия проекта.
- **Вход в агентов** хранится в именованных томах для `~/.claude` и `~/.codex` и переживает пересборку.
  Тома свои у каждого контейнера. Выйти из учётных записей полностью — удалить тома
  (`docker volume ls`, `docker volume rm …`).
- **Python и кэши uv** лежат в домашнем каталоге контейнера, а не в `Runtime/` проекта, поэтому не
  смешиваются с файлами хоста. После пересборки Python скачивается заново.
- **Сеть не ограничена.** Если агенту нужен только доступ к API, добавьте firewall по образцу
  эталонного devcontainer Claude Code: https://code.claude.com/docs/en/devcontainer
- Контейнер изолирует хост, но не проект: агент может изменить или удалить файлы проекта.
  Коммитьте перед автономным запуском.
