# Toolbox

Инструменты проекта и слой независимости от хостовой системы. От машины нужны только git и доступ
в интернет при первом запуске: uv и Python `tb` скачивает сам в `Runtime/tools/`, глобально ничего
не ставит. Удалили `Runtime/` — следующий вызов `tb` восстановит среду.

## Запуск

- macOS, Linux, Git Bash: `Toolbox/tb <команда>`
- Windows (PowerShell, cmd): `Toolbox\tb.cmd <команда>`

Справка: `Toolbox/tb --help`, `Toolbox/tb <команда> --help`. Сообщения `tb` всегда на английском,
пути в выводе — относительно корня проекта.

## Команды шаблона

| Команда | Назначение |
|---|---|
| `tb version` | Версия шаблона, имя, язык и профиль проекта |
| `tb setup [--agents a,b] [--clone-missing]` | Настройка машины: uv, адаптеры, git, Obsidian, Ресурсы |
| `tb kb search <запрос> [--type T] [--status S] [--resource R]` | Поиск в Знаниях |
| `tb kb show <путь\|slug>`, `tb kb related <путь\|slug>` | Заметка целиком; ссылки и обратные ссылки |
| `tb kb new <type> <slug> [--title T] [--folder]` | Новая заметка из `Knowledge/_templates/` |
| `tb kb index`, `tb kb lint`, `tb kb stale` | Индекс; проверка Знаний и `AGENTS.md`; кандидаты на перепроверку |
| `tb secrets scan [--staged] [пути…]` | Поиск секретов |
| `tb agents list\|link\|unlink\|doctor` | Адаптеры агентов на этой машине |
| `tb resources status\|clone\|add` | Ресурсы: состояние, клонирование, добавление в каталог |
| `tb obsidian setup` | Конфигурация хранилища Obsidian |
| `tb update fetch` | Скачать свежий релиз шаблона в `Runtime/update/` (дальше — skill `agentic-update`) |
| `tb hook <name> [--agent A]` | Обработчики хуков; вызываются агентами, не вручную |
| `tb run <script> [аргументы…]` | Запустить скрипт через uv |

## Как добавить инструмент проекта

Предпочтительно — Python-скрипт в `Toolbox/` с зависимостями прямо в файле (PEP 723). uv сам
поставит нужный Python и пакеты в изолированное окружение:

```python
# /// script
# requires-python = ">=3.12"
# dependencies = ["httpx>=0.27"]
# [tool.uv]
# exclude-newer = "2026-10-01T00:00:00Z"   # фиксирует версии пакетов на эту дату
# ///
"""Что делает инструмент и как его вызывать."""
```

Запуск: `Toolbox/tb run Toolbox/<имя>.py [аргументы…]`.

Подойдёт и любой другой скрипт, но тогда позаботьтесь о macOS, Linux и Windows сами (например,
пара `<имя>.sh` и `<имя>.cmd`). Правила:

- имена файлов — латиница, kebab-case;
- пути — относительно корня проекта, временные файлы — в `Runtime/`;
- никаких секретов в коде: читайте их из переменных окружения или `.env` (он в `.gitignore`);
- каждый инструмент — строкой в списке ниже.

## Toolbox/agentic/

Инструменты шаблона. Каталогом управляет шаблон: он обновляется через skill `agentic-update`,
а локальные правки приведут к конфликту при обновлении. Не правьте его — свои инструменты кладите
