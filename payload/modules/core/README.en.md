This is an Agentic Project — a workspace where an Agent (Claude Code, Codex and others) works across all of
the project's Resources and relies on Knowledge accumulated right here, under git, rather than in agents'
system directories.

## Getting started on a new machine

All you need is git, an Agent and internet access on the first run: Toolbox downloads everything else
into `Runtime/` by itself, without administrator rights.

```sh
git clone <project-repository-url>
cd <project-directory>
Toolbox/tb setup --agents claude,codex
```

On Windows (PowerShell or cmd): `Toolbox\tb.cmd setup --agents claude,codex`.

`tb setup` downloads uv and Python into `Runtime/`, creates adapters for the listed agents, applies git
settings (and Obsidian settings if the module is enabled) and shows which Resources are missing. The
`--clone-missing` flag clones the missing ones right away. You can rerun the same command at any time: it
restores the environment after `Runtime/` has been deleted and connects a new agent.

Then open the Agent in the project root.

## Structure

| Directory | Purpose |
|---|---|
| `Resources/` | Resources — what we work on: git repositories or plain folders. Catalog — `Resources/resources.toml` |
| `Knowledge/` | Knowledge — the project's persistent memory; an Obsidian vault |
| `Toolbox/` | Project tools and the `tb` entry point |
| `.agents/` | System files: skills, subagents, hooks, agent adapters, documentation |
| `Runtime/` | Temporary files, cache, downloaded tools; not in git |

The `.claude/`, `.codex/` and similar directories are generated by `Toolbox/tb agents link` and are not
committed to git.

## How to work

- Give the Agent tasks as usual. It checks Knowledge before making decisions, wraps up at the end of a
  session (skill `wrap-up`) and offers to commit the results.
- The Agent commits only when you ask.
- Knowledge is convenient to read and edit in Obsidian: open `Knowledge/` as a vault.
- Every now and then, ask for a review of Knowledge (skill `kb-review`) and plans (skill `plan-review`).
- To update the project from a fresh template version, ask the Agent: "update the project from the
  template".
