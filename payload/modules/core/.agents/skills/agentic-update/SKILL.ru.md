# Обновление проекта из шаблона

Skill намеренно тонкий: вся логика обновления живёт в свежей копии шаблона, поэтому обновляется
и сам механизм обновления. Ничего не меняй в проекте, пока не дойдёшь до шага 4.

1. **Чистое дерево.** Выполни `git status --porcelain`. Если вывод не пуст — покажи изменения
   человеку и остановись: их нужно закоммитить (Знания — через skill `kb-commit`) или убрать.
   Сам ничего не коммить и не откатывай.
2. **Загрузка.** Выполни `Toolbox/tb update fetch` (Windows PowerShell: `Toolbox\tb.cmd update fetch`).
   - `--ref <тег>` — только если человек назвал конкретную версию.
   - `--source <url>` — только по прямому указанию человека: источник обновлений по умолчанию берётся
     из `.agents/agentic.lock`, менять его может только человек.
3. **Нечего обновлять.** Если вывод — `Already up to date`, сообщи человеку текущую версию
   (`Toolbox/tb version`) и закончи.
4. **Инструкция из свежей копии.** Иначе команда напечатает путь вида `Runtime/update/<версия>/`.
   Прочитай `Runtime/update/<версия>/setup/UPDATE.md` целиком и выполняй его. С этого момента
   UPDATE.md главнее этого skill: при расхождении следуй UPDATE.md.

Если `tb update fetch` завершился ошибкой (нет сети, нет доступа к источнику, нет тегов) — покажи
человеку сообщение об ошибке и остановись; не скачивай шаблон другими способами.
