Это Agentic Project — рабочая среда, в которой Агент (Claude Code, Codex и другие) работает над всеми
Ресурсами проекта и опирается на Знания, накопленные здесь же, под git, а не в системных каталогах агентов.

## Начало работы на новой машине

Нужны только git, Агент и доступ в интернет при первом запуске: всё остальное Toolbox скачает сам
в `Runtime/`, без прав администратора.

```sh
git clone <url-репозитория-проекта>
cd <каталог-проекта>
Toolbox/tb setup --agents claude,codex
```

На Windows (PowerShell или cmd): `Toolbox\tb.cmd setup --agents claude,codex`.

`tb setup` скачивает uv и Python в `Runtime/`, создаёт адаптеры для перечисленных агентов, применяет
настройки git (и Obsidian, если модуль включён) и показывает, каких Ресурсов не хватает. Флаг
`--clone-missing` сразу клонирует недостающие. Ту же команду можно повторить в любой момент: она
восстанавливает среду после удаления `Runtime/` и подключает нового агента.

Затем откройте Агента в корне проекта.

## Структура

| Каталог | Назначение |
|---|---|
| `Resources/` | Ресурсы — то, над чем работаем: git-репозитории или обычные папки. Каталог — `Resources/resources.toml` |
| `Knowledge/` | Знания — постоянная память проекта; хранилище Obsidian |
| `Toolbox/` | Инструменты проекта и точка входа `tb` |
| `.agents/` | Системное: skills, субагенты, хуки, адаптеры агентов, документация |
| `Runtime/` | Временные файлы, кэш, скачанные инструменты; не в git |

Каталоги `.claude/`, `.codex/` и подобные генерируются командой `Toolbox/tb agents link` и в git не попадают.

## Как работать

- Ставьте задачи Агенту как обычно. Перед решениями он сверяется со Знаниями, в конце сессии
  подводит итоги (skill `wrap-up`) и предлагает их закоммитить.
- Коммиты Агент делает только по вашей просьбе.
- Знания удобно читать и править в Obsidian: откройте `Knowledge/` как хранилище.
- Время от времени просите провести ревью Знаний (skill `kb-review`) и планов (skill `plan-review`).
- Чтобы обновить проект из свежей версии шаблона, попросите Агента: «обнови проект из шаблона».
