# Миграции

Детерминированные скрипты, которые приводят структуру проекта и формат Знаний к новой версии шаблона.
Их запускает `setup/update.py apply` после обновления файлов — для каждой версии в интервале
(установленная, новая], по возрастанию версии.

- Имя файла: `<x.y.z>_<slug>.py`, где `x.y.z` — версия шаблона, в которой появилась миграция,
  `slug` — латиница, цифры, `-` или `_`. Например: `0.2.0_rename-status.py`.
- Скрипт определяет функцию `migrate(root: Path) -> None`; `root` — корень проекта.
- Миграция **идемпотентна** (повторный запуск ничего не меняет) и **детерминирована** (без сети,
  дат и случайности, результат зависит только от файлов проекта).
- Доступны стандартная библиотека Python 3.12, `tomli-w` и `pyyaml`. Файлы читай и пиши в UTF-8
  с переводами строк `\n`, пути — через `pathlib`.
- Ошибка — исключение с понятным сообщением: `apply` остановится и не обновит `agentic.lock`.
- Миграцию описывай в `CHANGELOG.md` в подразделе «Миграции» версии.
